# IziWiki

Este Wiki serve como um repositório central para os padrões e boas práticas de desenvolvimento de software da empresa. O objetivo é fornecer uma referência abrangente para todos os desenvolvedores, garantindo a consistência, a qualidade e a eficiência em todos os projetos de software.

### Instalação e execução:

Para instalar e executar este projeto é necessário ter uma versão recente do Python e Python Package Manager instalados no seu computador.

Para verificar se você já possui eles instalados, abra seu terminal e execute as seguintes instruções:

```bash
$ python --version
Python 3.8.2
$ pip --version
pip 20.0.2 from /usr/local/lib/python3.8/site-packages/pip (python 3.8)

```

Caso não possua Python e pip instalados, será necessário instalá-los:

- Python: https://www.python.org/downloads/

Se você baixar uma versão recente do Python o pip normalmente já está incluso na instalação por default. Contudo, pode ser necessário atualizar o pip para a última versão. Isso pode ser feito com o comando:

`pip install --upgrade pip`

Após a instalação do Python e pip, você estará apto a instalar o MkDocs.

`pip install mkdocs`

Para checar a instalação e verificar a versão:

```bash
$ mkdocs --version
mkdocs, version 1.2.0 from /usr/local/lib/python3.8/site-packages/mkdocs (Python 3.8)
```

Guia de instalação: https://www.mkdocs.org/user-guide/installation/#installing-mkdocs
