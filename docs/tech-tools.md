<h2 id="dbeaver">DBeaver</h2>

Sugere-se o uso do [DBeaver](https://dbeaver.io/about/) como Sistema Gerenciador de Banco de Dados (SGBD).
DBeaver possui suporte multiplataforma, suporte a múltiplos bancos de dados, interface gráfica intuitiva, é Open-source, dentre diversos outros recursos.


<h2 id="extensoes">Extensões VSCode</h2>

<p>
Sugere-se o uso do VSCode como editor de texto. Dentre os diversos pontos positivos do VSCode está o uso de extensões que permitem diferentes funcionalidades e recursos dentro do próprio editor, colaborando com a produtividade do desenvolvedor.
</p>

- [GitFlow](https://marketplace.visualstudio.com/items?itemName=vector-of-bool.gitflow)
<p>Extensão que auxilia na criação/gerenciamento do fluxo de trabalho com o git. Ao instalar a extensão você terá acesso na paleta de comandos (CTRL + Shift + P) alguns recursos para trabalhar utilizando o gitflow.</p>

- [Git Graph](https://marketplace.visualstudio.com/items?itemName=mhutchie.git-graph)
<p>Extensão que auxilia na visualização gráfica do seu repositório git e ainda permite que algumas ações git sejam realizadas através da própria interface gráfica.</p>

- [Rest Client](https://marketplace.visualstudio.com/items?itemName=humao.rest-client)
<p>Extensão que permite realizar requisições no padrão REST diretamente através do VSCode. É especialmente útil por manter a coleção de requisições da aplicação dentro do próprio código-base sem necessidade de softwares externos como Insomnia ou Postman. Auxiliando ainda, como uma forma de documentação da aplicação.</p>


<h2 id="redis-desktop">Another Redis Desktop Manager</h2>

[Another Redis Desktop Manager](https://github.com/qishibo/AnotherRedisDesktopManager) é um ferramenta de interface gráfica intuitiva que auxilia na gestão de banco de dados em memória. Possui navegação na estrutura de dados do Redis, gerenciamento de dados, execução de comandos e visualização e monitoramente dos dados.
