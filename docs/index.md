# Bem-vindo ao Wiki Técnico Bankizi

Este Wiki serve como um repositório central para os padrões e boas práticas de desenvolvimento de software da empresa. O objetivo é fornecer uma referência abrangente para todos os desenvolvedores, garantindo a consistência, a qualidade e a eficiência em todos os projetos de software.

<h3> O que você encontrará aqui: </h3>
- <strong>Padrões de codificação:</strong> Diretrizes para formatação de código, documentação, nomeação de variáveis ​​e outros aspectos da escrita de código.
- <strong>Boas práticas de desenvolvimento:</strong> Recomendações para metodologias de desenvolvimento, gerenciamento de versão, testes e outras áreas importantes do processo de desenvolvimento de software.
- <strong>Tutoriais e guias:</strong> Instruções passo a passo para tarefas comuns de desenvolvimento, como configurar ambientes de desenvolvimento, usar ferramentas específicas e implementar funcionalidades comuns.
- <strong>Documentação de arquitetura:</strong> Descrições detalhadas da arquitetura dos sistemas da empresa, incluindo componentes, interfaces e padrões de design.

<h3>Como contribuir:</h3>

Este Wiki é um recurso colaborativo e todos os membros da equipe são incentivados a contribuir. Ele foi construído utilizando MkDocs uma plataforma para documentação de projetos de software através de MarkDown. 
Para saber mais: [mkdocs.org](https://www.mkdocs.org)

Nele você pode:

- Editar páginas existentes para adicionar novas informações, corrigir erros ou melhorar a clareza.
- Criar novas páginas para documentar novas práticas, ferramentas ou tecnologias.
- Fornecer feedback sobre o conteúdo do Wiki.

INFO: **OBS**
Este Wiki é um trabalho em andamento e está sendo continuamente atualizado. Esperamos que seja um recurso valioso para todos os stakeholders da empresa.
